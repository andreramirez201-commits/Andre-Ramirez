Second Brain, a persistent memory system built for organizations

The operating system I run my own work on. Off-the-shelf assistants forget you between sessions, so I built the memory layer myself: session hooks inject a curated context file at start, every transcript is captured at session end, and a nightly reflection job promotes only the durable signal into long-term memory. Recurring processes get frozen into skills so the same work is never re-improvised twice.

Worth reading for: the security model. An operational AI system may simultaneously touch private company data, untrusted external information and systems capable of taking action, so permissions are explicitly defined by service.

Legal intake voice agent

A 24/7 intake agent for law firms, built end to end, not yet sold to one. It runs the qualifying conversation a paralegal would run, captures matter details against a structured intake schema, and delivers a written summary before the caller has hung up. Worth reading for: the intake schema. The hard part isn't getting an agent to talk. It's getting a consistent, complete, structured record out of an unstructured, often emotional phone call, every time.

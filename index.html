Running daily Solo build Agent memory · Private

Second Brain, a persistent memory system for an AI agent

The operating system I run my own work on. Off-the-shelf assistants forget you between sessions, so I built the memory layer myself: session hooks inject a curated context file at start, every transcript is captured at session end, and a nightly reflection job promotes only the durable signal into long-term memory. Everything it declines to promote stays retrievable through a full-text index over the logs. Recurring processes get frozen into skills so the same work is never re-improvised twice.

It is built on Interpretable Context Methodology: the folder structure is the agent architecture, every context file is plain markdown a human can read and audit, and a session loads only the layer it needs instead of the whole workspace. Nothing about how it thinks is buried in a vector store I cannot open and correct.

Worth reading for: the security boundary. Any agent with access to your real life trips the lethal trifecta at once, private data plus untrusted incoming content plus a way to send things out. You cannot remove all three and still have it be useful, so each one gets constrained deliberately, and permissions are declared per service in a single file I can read in one sitting. That decision is why it holds finances and private notes and I still sleep fine.
